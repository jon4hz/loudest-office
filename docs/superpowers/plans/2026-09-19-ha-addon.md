# Home Assistant App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run the visualizer on the Home Assistant Pi as a local app, deployed with `task addon:deploy`.

**Architecture:** The app's folder is the office build context (`Dockerfile`, cross-compiled `spectrum`, `sendspin-pipe` sources) plus `addon/config.yaml`. The Supervisor cannot pass arguments, so `spectrum` takes its config path from `SPECTRUM_CONFIG` and reads the Supervisor's `/data/options.json` directly (JSON is YAML).

**Tech Stack:** Go 1.27 (viper/pflag, existing), go-task, `tar` over `ssh`, Home Assistant Supervisor (`ha apps`, `ha store`).

**Spec:** `docs/superpowers/specs/2026-09-19-ha-addon-design.md`. Read it first; it is normative for behaviour, this plan for order and names.

## Global Constraints

- **No state-changing git command at all: no commit, add, stash, merge, push. The user owns git history and works in the same tree.**
- Module `github.com/jon4hz/loudest-office/visualizer`; no new dependencies; stdlib `testing` only; `CGO_ENABLED=0 go build ./...` keeps working.
- The `Dockerfile` in `ansible/roles/visualizer/files/build/` does not change.
- App slug `loudest_visualizer`; on the Pi it is `/addons/loudest_visualizer` and the Supervisor knows it as `local_loudest_visualizer`.
- Match the surrounding files' style and comment density. Build exactly what is listed.
- Tasks 1 and 2 touch nothing outside this repo. Only task 3 talks to the Pi.

**Files:** Modify `visualizer/config/config.go`, `visualizer/config/config_test.go`.

**Produces:** `SPECTRUM_CONFIG=/path` names the config file when `--config` is not given; the flag wins.

- [ ] **Step 1: Failing test.** Append to `config/config_test.go`:

```go
func TestConfigFromEnv(t *testing.T) {
	dir := t.TempDir()
	env := filepath.Join(dir, "options.json") // the Home Assistant app's options file: JSON is YAML
	if err := os.WriteFile(env, []byte(`{"bands": 12, "listen": ":8099"}`), 0o600); err != nil {
		t.Fatal(err)
	}
	t.Setenv("SPECTRUM_CONFIG", env)
	f := pflag.NewFlagSet("spectrum", pflag.ContinueOnError)
	Flags(f)
	if err := f.Parse(nil); err != nil {
		t.Fatal(err)
	}
	c, err := Load(f)
	if err != nil {
		t.Fatal(err)
	}
	if c.Bands != 12 || c.Listen != ":8099" {
		t.Errorf("got bands %d, listen %q: the file named by SPECTRUM_CONFIG was not read", c.Bands, c.Listen)
	}

	if c, err = load(t, "bands: 7\n"); err != nil { // load passes --config: the flag wins
		t.Fatal(err)
	} else if c.Bands != 7 {
		t.Errorf("bands = %d, want the --config file's 7", c.Bands)
	}
}
```

### Task 2: app files, deploy task, README

**Files:** Create `addon/config.yaml`. Modify `Taskfile.yml`, `README.md`.

- [ ] **Step 1: `addon/config.yaml`** — exactly the YAML block in the spec's "Files" section, preceded by this comment:

```yaml
# Home Assistant app (formerly add-on). `task addon:deploy HA=<user>@<pi>` copies this file
# next to the office image's build context into /addons/loudest_visualizer on the Pi.
# The options are spectrum's config keys: spectrum reads /data/options.json as its config.
```

- [ ] **Step 2: Taskfile.** After `visualizer:build` add:

```yaml
  addon:deploy:
    desc: Copy the Home Assistant app to the Pi and rebuild it (HA=<user>@<pi>, a user with sudo)
    deps: [visualizer:build]
    requires:
      vars: [HA]
    vars:
      DIR: /addons/loudest_visualizer
      SLUG: local_loudest_visualizer
    cmds:
      # one tar stream: the app's config next to the office image's build context
      - >-
        tar -c -C addon config.yaml
        -C ../ansible/roles/visualizer/files/build Dockerfile spectrum sendspin-pipe
        | ssh {{.HA}} 'sudo rm -rf {{.DIR}} && sudo mkdir -p {{.DIR}} && sudo tar -x -C {{.DIR}} --no-same-owner'
      - ssh {{.HA}} 'sudo ha store reload'
      # fails before the first install: then install it in the UI, or `ha apps install {{.SLUG}}`
      - cmd: ssh {{.HA}} 'sudo ha apps rebuild {{.SLUG}}'
        ignore_error: true
```

Verify the archive without touching the Pi: run `go-task visualizer:build`, then the `tar -c …` half of the pipe into `tar -t` and check it lists exactly `config.yaml`, `Dockerfile`, `spectrum` and the `sendspin-pipe/` tree (`go.mod`, `go.sum`, `main.go`, `pcmout/…`), with no leading directories. Validate the YAML: `python3 -c "import yaml,sys; yaml.safe_load(open('addon/config.yaml')); yaml.safe_load(open('Taskfile.yml'))"` and `go-task --list` shows `addon:deploy`. `go-task addon:deploy` without `HA` must fail with the requires message, not run anything.
